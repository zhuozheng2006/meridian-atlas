# 经纬纪下一版：产品与资料对照审计

审计日期：2026-10-02。审计范围：当前本地 2.1 源码、README、覆盖报告、验证报告和两张实际预览截图；对照项目的官方页面、文档或其官方 GitHub 仓库。未登录商业产品，未逐项操作全部竞品界面。下文明确区分“官网列出”“本地代码可确认”与“建议”；不存在已经验证“全面超过所有竞品”的结论。

## 最重要的结论

目前最明显的不足是地图信息的层次，而非描边圆角。`dist/map-engine.js` 的主地图只有陆地、海岸线、疆域与选择轮廓，最大缩放级别为 7；地图上没有地形晕渲、水系或独立城市层。汉朝阅读截图中，山地、平原与河谷被同样的政体颜色覆盖，所以即使边缘顶点继续加密，仍会像色块示意图。应当优先建立“地貌—水系—聚落—疆域—事件”的制图层次，再增加可核实的专题资料。

“高精细地图”至少有三种精度：底图的空间细节、历史政治范围的证据精度、显示时的几何保真度。高分辨率现代地貌可以立即引入；历史疆域的顶点更多，并不自动证明该边界在某一年更准确。样式应保持精细，产品资料页应简洁说明这三种差别。

## 本地 2.1 基线

来自本地 README、`docs/CONTENT-COVERAGE.json`、`docs/VALIDATION.md` 和地图源代码：

- 疆域：13,380条政体时段记录、385条关系记录、11,232个几何；前3400年至2024年。已有0.02度细节展示几何和0.04度概览，不是原始最高保真几何。
- 内容：343条双语事件、1,450实体档案、23篇双语文明概览、47条侧记。330份档案包含1,885项附引证声明；资料密度不均。
- 主题事件：政治97、社会56、科技46、文化39、贸易37、战争34、宗教24、灾害10。它们是事件文本类别，不能称为独立战争/贸易地理数据库。
- 产品：双年份同步对照、六栏目国家档案、双语切换、12条专题、筛选与分享已实现。34组检查和三种视口验证是已有发布依据，不能代替新版验证。
- 当前地图没有地形、水系、历史城市、贸易路线；二维平面和地球是同一简化底图的两种投影。截图中主地图景物与信息密度较低，历史阅读区比地理解释更成熟。

## 八项发布验收指标

以下是建议的发布闸门，尚未执行，不应提前写成“已通过”。

1. **几何保真**：全部原记录id、时间、引用保持一致；无新增无效几何。至少对8个复杂海岸/边界样本，在默认和区域缩放级别保存对比图。高细节展示必须能追溯到具体源几何，不对疆界人为平滑。若使用简化，报告容差、顶点数和最大偏差，而不是“超高精度”营销词。
2. **地貌与聚落可读**：至少8个跨洲测试场景可辨认主要山地、水系及城市；都市标签不遮住关键国家标签或主控件。历史城市100%具备坐标、时间依据及来源字段；现代城市参考与历史城市状态分开。
3. **时间与身份正确**：快速切换30次年份、两张比较地图各自切年、开关详情和图层后，标题/多边形/城市/事件/国家正文属于同一已提交年份。前1年直接接公元1年；不存在双重快捷键动作和乱序回写。对至少30个跨地区、跨时代实体人工复核名称与时代身份。
4. **搜索与比较完成任务**：20组中英查询覆盖城市、国家与事件；选择结果后定位正确，键盘可操作；深链接重载恢复年份、语言、投影、图层及选中项。双年份地图能明确说明正在比较的对象与年份，而非仅两张彩色图。
5. **响应与资源预算**：固定记录设备、浏览器、窗口与网络条件，冷启动3次、热启动3次、连续切年30次。把“首幅可交互地图时间”和常规页面指标分别记载。建议目标 LCP≤2.5秒、INP≤200毫秒、CLS≤0.1；这些来自[Core Web Vitals](https://web.dev/articles/vitals)，本机测试只能称实验结果，不能冒充真实用户75分位。缓存切年目标≤200毫秒；更慢请求在300毫秒内有明确加载反馈。
6. **故障与离线恢复**：逐类阻断目录、边界、地形瓦片、城市与档案请求；出现可理解的状态和重试，已成功的历史地图保留。外部地形不可用时回落本地地理层；离线功能边界在来源页说明，不能白屏或无限转圈。
7. **阅读和操作可达**：390、834、1440宽度及200%文字缩放不产生正文横向溢出；所有核心任务可由键盘完成，焦点可见且关闭面板返回原入口。主触控目标建议44px；WCAG 2.2 AA最低要求实际是24px或相应间距例外，见[W3C解释](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)，不要误报44px为所有控件强制标准。三种语言模式逐项检查，简体正文不含繁体残留。
8. **来源与发布可复现**：所有新增数据源均保留许可证、固定版本/抓取日期、转换记录；城市、事件和档案能点到实际依据。包内容与线上构建一致，不含私密凭据；新版测试记录、覆盖统计和至少桌面/手机真实截图随交付更新。

## 不能用本轮视觉改动替代的研究工作

现有数据不能支持“全球任意一天的完整疆域”“历代所有重要城市与人口”“全球战争及军队运动”“完整地形与海岸历史演变”。Phersu的专业资料深度、Running Reality长期积累的街道/建筑/运动资料、OHM社区的局部高细节均不能只靠界面重做即被超越。新增图层本身也不构成超越：没有来源、日期或空间依据的图层只会扩大误导。

本轮可兑现的产品目标是：精细自然底图与真实地形可读；有年代的城市进入地图；中文与英文阅读流畅；搜索、对照、键盘、移动端与失败恢复可靠；每项历史断言可追踪。下一轮应以覆盖矩阵指向具体缺口，例如东南亚城市史、撒哈拉以南非洲贸易、前殖民美洲道路，而非继续宣称抽象的“更全面”。
