Shipped data and meaning
47,477 untouched canonical-sheet records, 373 unique PolIDs, 444 polity metadata rows,
135 variables. 1,446 rows supply Date.From and/or Date.To; 46,031 do not.
No-date rows keep their original source phase context and are never filtered by map year.
The reviewed first pilot is preserved in full: 424 rows including 61 explicitly dated rows.
The workbook includes administrative/coding metadata (for example RA names); record totals
must not be presented as a count of independently verified historical facts.

Dictionary
All 135 original variables have Simplified Chinese display/search labels; source English names
and source values are unchanged. The priority selection remains exactly the original 26 variables.
Duration is interpreted by Section/Subsection: coding-table dates vs ritual duration in hours.
Units are shown only with numeric values. Present/absent/inferred/unknown/suspected unknown,
uncertain/disputed/range/list and missing fields remain distinct.
The workbook does not contain every statement's rationale and bibliography. Source workbook
row numbers and the original codebook are provided; no per-row scholarly references invented.

Startup and share state follow-up
- Research routes do not request MapLibre, core map catalog/events or create WebGL canvases.
- Default map routes preload catalog/renderer in parallel; first map navigation initializes once.
- Source view and research view can be visited without constructing a map.
- Research URL keys: seshat, srDomain, srVariable, srQ, srFind, srPage. Whitelist, limits, defaults
  and actual variable validation apply. Snapshots survive Sources round trips and language changes.

  applies the current language. Stale original place-link loads cannot steal a later navigation.
- Number formatting is display-only. Workbook values, raw fields and downloads are untouched.
- Added node scripts/validate-research-routing.mjs: 13/13 direct app-function checks, including
  rejected WebGL, delayed renderer/deep links, repeated initialization and URL state validation.
