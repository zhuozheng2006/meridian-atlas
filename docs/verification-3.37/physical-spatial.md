## 几何与年代语义

输入就是已发布的 Natural Earth 物理数据。输入曾按 1e-5 度量化；本轮不再次取整或简化，也不改变历史疆域。

每格以同一陆地并集计算 `land ∩ cell` 和 `cell − land`。海岸线从原始陆地边线作为线裁入格网，移除世界坐标截断边；格网闭合边从未用作海岸。河流、湖泊按源要素编号保留属性和片段。Loire 的一个源要素本来为空，保留为空，不制造河段。

独立审计以实际 JavaScript `compactGeometry` 解码结果为基准，不导入 Python 构建器的解码代码。读取每个输出文件后复核：

- 648 个包、17,241 个闭环全部有效。
- 每格土地和水域无面积重叠、无缺口；全球重组差集约 2.0e-13 平方度，全球无缺口/重叠。
- 每格海岸几何与原始海岸线裁剪结果拓扑完全相等。
- 1,454 条非空河流、1,355 个湖泊重组后保持来源几何和属性，233 个湖中孔保留。
- 12,028 个分类点（含日期线两侧 28 点）无分类差异。
- 故意使用裁后陆地轮廓的负例多出约 8,152.83 度的线长；不能通过真实海岸相等检查。

完整数值见 `physical-spatial-geometry-audit.json`。浮点线重组审计容差为 1e-8 度（赤道约 1.1 毫米），未用于修改或取整输出坐标。

## 运行时约定

五类几何共用单一 `physical-grid` GeoJSON source，通过属性分层绘制。一份视野只调用一次 `setData`；等待 source ready 后显现，土地与水域不会由两个异步 source 分别替换。旧完整概览作为背景与失败回退保留。

进入已缓存覆盖内无需下载或重新提交。跨出覆盖先恢复概览；过期请求和旧 worker 完成事件不激活旧视野。失败清除相关缓存；重试可重建 source。原始海岸线在细节激活时隐藏，避免叠成双线。地形开关、海岸对齐、远程参考与 HALC 历史地貌仍独立控制。

`Geography.landLayer`、`Geography.coastWaterLayer` 向区域覆盖与地图点击提供当前可见物理层。`Geography.destroy()` 清理格网及湖泊监听器。

## 重现

```sh
# 无额外 npm 依赖：行为与完整文件校验
node scripts/validate-physical-grid.mjs
node scripts/validate-geography.mjs

# 构建、独立几何审计需要 Shapely；输出目录可自行指定
python scripts/cartography/build-physical-spatial.py --root . --output /tmp/atlas-physical-spatial
node scripts/cartography/decode-published-physical.mjs . /tmp/atlas-physical-decoded
python scripts/cartography/audit-physical-spatial.py --source /tmp/atlas-physical-decoded --cells /tmp/atlas-physical-spatial
```

运行时回归覆盖单 source 成帧、读取阈值、覆盖内复用、跨视野回退、旧请求、旧 worker、坏包、部分失败、source 错误重建、开关、历史地貌顺序协调、销毁、日期线及全部磁盘文件哈希。`validate-geography` 保留 31 项原有与更新后的地理行为检查。

本说明中的几何与运行时检查不替代真实浏览器接缝、瓦片到达时序和阅读体验检查；浏览器记录由本轮主流程另行保存。
