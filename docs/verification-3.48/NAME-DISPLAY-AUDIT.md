# 经纬纪 3.48：政体名称与年代显示审计

基线：`9a9ded84`。资料实读与候选验证：2026-10-10。全部变更为独立候选，未操作主仓、浏览器或部署。

本批核查了 Cliopatria 的 13,765 条已交付记录，其中政体记录 13,380 条。修正 23 组精确规则、82 条原记录的显示名称；原始字段、Wikidata ID、百科链接、年代、面积与坐标均不改写。该范围是一次名称审计，并非对全球全部历史年代和疆域准确性的认证。

## 问题机制

`refresh_catalog_labels.py` 用来源百科页面与 Wikidata 的链接关系核对中文标签。链接一致能确认网页关联，却不能保证该百科实体就是当前年份、当前轮廓所指的历史实体。全局图、检索、国家阅读器随后分别使用 `zhName`、`name` 与专题标题，使同一错误可以在中文、英文次行和档案中独立出现。

- `British Africa` 原名是地理集合，百科关联却是 `Scramble for Africa`，中文变成了“瓜分非洲”。
- `Denmark-Norway` 被源数据沿用到 1939 年，1940 年还出现一条仅含法罗群岛的同名轮廓。
- `French Fourth Republic` 在源数据中已有 1945 年记录，比 1946 年宪法早。此处英文原名本身就需要按年显示说明。
- 东、西突厥分别有源记录，却共用“突厥汗国”的实体译名；《史记》中的具体封国也被译成集合名“项羽十八诸侯”。
- 11 世纪 `Norway-Denmark` 关联了后世丹挪联合实体。恢复字面名称能保留原档案身份，但不能认证其完整起止年代。

TNA 部分 HTML 页面返回 403，Discovery 页面要求浏览器校验；这些失败记录仅保留在本任务证据目录，未用作事实依据。所用 PDF 是该机构公开可读的独立文档。《史记》的另一检索站点返回 403 后，使用独立公开原典转录；没有绕过登录或访问校验。

## 范围扫描与待核事项

机器可复核的完整名单保存在 `audit.json`，并交付到 `docs/verification-3.48/name-display-audit.json`：

- 62 组多个源名称共用同一中文实体标签的候选集合。
- 214 条关联标题包含历史过程、列表或集合用语的候选政体记录。
- 324 条源名带 Eastern / Western / Northern / Southern / Upper / Lower / Land / Water 的记录。
- 已有资料中的 880 条 `potential_conflict` 时间兼容性标记。

这些是审查线索，数量不能当作“发现的错误数”。王朝与国家可合法共用常用名；父集合和组成项也可能使用相近名称。本批只有上述 82 条经来源支持后进入显示规则。

下一步仍需研究：Southern Xiongnu、Eastern / Western Kushans、Eastern Kara-Khanids / Western Karakhanid Khanate、Land / Water Chenla 的标签范围；东、西突厥具体源分期的年代；1046—1055 年 Norway-Denmark 完整区间；前 208—207 年 Dai / Jibei 与前 206—204 年诸封国逐年存在情况。古典文本本身记载了废立与合并，因此本批不能把所有源区间认证为每个封国完整存续年代。

## 显示与事实隔离

规则必须同时匹配 `id + name + start + end + type`，并提供记录内部的真实非零整数年份。无年份、无效年份、年份在记录外、身份或分期改变时不套用覆盖；无有效年份的通用命名函数回退到原源名称。

地图主行和英文次行、国家档案标题与概览、政体检索、文明列表、城市返回按钮都使用同一按年 API。跨年代检索显式挑选记录内年份并显示该年份；相同源名称的不同显示时期独立成组，不把“丹挪联合”点击跳转成后来的“丹麦”。

82 条记录暂停使用关联集合/冲突实体的百科资料、编辑篇章和首都关系。空间筛选的聚落与人口记录照常保留。源链接、原名字、原年代以及同名疆域时间链保留；相关事件按修正名称和当前源记录的区间筛选，避免旧实体别名引入未来政体。

名称说明集中放在 Sources，不添加每段警告。导出含原始 `record`，并另附 `display`：当前年、双语显示名和匹配规则，不篡改原始导出字段。
