## 6. 词典、译名和历史语义边界

173 个变量均有独立双语显示定义。18 项仍需取得当前版精确定义；`sync_rel_pra_ind_beli` 等缩写不猜译。此前来源建议映射中发现的 19 项错误对应已排除（例如把青铜概念对应到铁），原始建议仍归档可审查；所有变量对照均 `allowRecordMerge=false`。只在有明确依据时标单位，数字双端值不默认当作上下限或均值。

626 个阶段名称候选：368 项完整译名、13 项部分译名、245 项暂保留英文。运行时采用 368 个完整绑定译名，其余原名回退；翻译不等于核实来源年代或政治实体性质。原 ID、编号、名称、源日期/工作表/行及区域共同约束绑定，不能用于地图 QID 自动关联。秦的来源阶段始于 -338、一个马六甲阶段为 1270—1415、Napoleonic France 为 1816—1870 等问题已保留来源值和审查注记，没有静默修正。

Polaris 的时间异常均照录并在模型中可识别：54,826 行无双端日期，8 行单边日期，4 行含源零年，117 行观察时间超出原阶段，8 行数值端点逆序；另有 1 个阶段终年为 0。无日期观察仅显示来源阶段上下文，**不能补成阶段起始年，不能随地图年份筛掉或当逐年事实**。例如明 Crisis 表第 26 行为 1644—1683、印加第 120 行为 1528—1570，可能是后果时间，不能裁剪到王朝阶段；罗马中期 Social complexity 第 1362 行的 -100 也保留待复核。

Crisis 的 21 个结果是 A/P/IA/IP/SU/DIS 等字符串编码，不是布尔。166 行保持 166 条，不拆成数千条来增加记录量。`is_disputed` 为 140 空/26 false；`is_uncertain` 为 143 空/23 false。空值不转 false；源未标记争议不等于历史事实已确证。`DIS`、`A~P`、`P~A` 的细义仍待定义，不擅自细化。关联政体字段 120 行双空、46 行有有效关联，保留源 ID 与编号。

Polaris XLSX **没有逐行论证、引用书目或编码依据文本**；本轮实现源行追溯，没有补齐这层历史证据。官方详情/API 直接获取曾返回 403，不重试绕过；官方仓库中的 `LLM*_responses.csv`/道路示例 responses 是模型试验输出，已排除为史料来源。固定 Polaris README 没有明确许可声明，不能套用 Equinox 许可；旧 Equinox README 与仓库 LICENSE 的冲突也继续记录。
