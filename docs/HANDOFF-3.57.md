# 经纬纪 3.57：西亚古典边界、汉唐名称核查与流式加载

延续原网站与访问范围。部署及 GitHub 提交见本批 `verification-3.57/publication.json`。

## 本批交付

- **西亚**：接入 UNC Ancient World Mapping Center 的公元 117、200 年罗马疆域截面。每年112个原始多边形组合成一个帝国记录，所有坐标、岛屿、内环保留；200年另显示81条未命名行省线。来源文件无损压缩后分别158/159/62KB左右，完整来源属性仍在下载文件中。视野中心位于东经25—52、北纬20—46，且年份严格为117/200时自动启用，其他年份继续使用原有概览。未把罗马记录当成整个西亚政体集合。
- **汉唐名称**：完成30/420条，12条汉代名称、18条唐代天宝元年郡名。以年份、PrefID、PrefNAM、ProvNAM同时匹配，避免同名误配。原始名称可检索、在弹窗中阅读，下载记录附名称考证而不修改sourceRecord。信都与涿郡修正拉丁拼写；左冯翊保留Zuo Pingyi。庭州/北庭与阶州等暂留待复核。
- **加载**：公共gzip读取器收到头部即开始解压，网络继续传输时同步处理；取消原先整份压缩体的收集与第二次复制。适用于已有概览、汉唐、CHGIS与新AWMC等调用路径。覆盖分块头部、已被服务器解压、UTF-8分块、空包、损坏包、中断重试、并发共享与下载结束前已产生解压输出等验证。未宣称固定百分比提速。

## 证据与范围

`early-asia.json`校验来源文件哈希、所有坐标、精确年份、行省线排除政体计数、名称身份与下载原记录不变。`json-streaming.json`验证流式行为。完整测试、HTTP检查、浏览器截图和线上文件核验同在本批目录。

浏览器检查发现MapLibre可将线要素出现在fill查询结果里，本批为地区填色明确加Polygon过滤，并在记录分组与命中阶段排除行省线，避免把线条计作国家或区划。旧VM测试需显式加载新增AWMC依赖，修复后重跑整套测试。

**南亚本批未新增可靠详图。** NATMO古代文化图的年代与可取数据仍未核实；物理图的生产年份不能视为古代政体年份；基于现代GADM拼装的示例不能作为古代高精度边界；宽年代示意图也不能直接用作逐年边界。检索结果及下一步见`south-asia-source-review.json`。早期西亚除罗马之外的诸政体亦未因此补齐。

## 接续重点

1. 获取并核对NATMO Ancient India Cultural原图/图例/年代，或有清晰图版与年代的学术历史图集，再做可追溯配准与数字化；不要从现代行政边界生成古代疆域。
2. 继续按记录核查汉唐剩余390条名称及合并单元，区分年度名称、上级区划和几何可信度。
3. 为无详图区域寻找更好原始边界；现有曲线只是画法，不增加史料精度。测量低速网络的首帧、解压与绘制时间后，优先处理真正的瓶颈。
4. AWMC目前严格两年、西亚触发。可评估更多明确年份图层与范围，但不得将单年几何套用整个朝代。
