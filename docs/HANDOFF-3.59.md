# 经纬纪 3.59：详图复用、跨区预加载与唐代名称

## 审视当前成果

3.58.1 已具备全球概览、若干有明确年代的地区详图、双语档案和来源阅读入口。主要短板仍是地区与年代覆盖不均、原始概览边界较粗、名称审校未完成，以及缺少真实低速网络下的整站耗时对照。南亚三组学术图版目前是研究入口，尚未转化成逐年矢量边界。

本轮检查发现两项可直接修复的加载问题：概览已使用内容指纹缓存，但大部分地区详图仍强制向服务器校验；中国不同经度带共用同一预加载标识，导致同一年跨带平移时跳过目标带预加载。

## 本轮改进

- **117 个既有详图包加入指纹缓存**：汉唐分带13、CHGIS世纪包23、CShapes年代包15、OHM压缩快照33及原始回退包33。连同已有270个概览包共387个。精确匹配文件路径和SHA-256，正确请求采用浏览器私有长期缓存，错误指纹返回412。索引、AWMC静态文件、归档、未知路径保持原策略。没有新增边界坐标或改写数据。
- **跨分区预加载**：预加载标识包含地区身份与年份。地图在详图显示门槛前平移到另一个中国分带时，会准备目标分带；打开详图复用同一请求。相同分带不重复请求，失败可重试，年份变化和关闭图层均受验证。
- **22 条唐代名称**：淮南道11、江南东道11；按《旧唐书》卷40核对天宝元年名称。两条源名为Chu Zhou的记录分别对应永阳郡（滁州，190）及淮阴郡（楚州，208）；括州对应缙云郡；舒州742年对应同安郡，不提前使用757年的盛唐郡。累计102/420条，汉62、唐40，尚余318条。原名、来源编号及原始下载记录保留。
- **出处呈现**：新名称携带中英文来源标题；阅读器优先显示各条出处自身的英文标题。原文人口数仅作身份交叉核对，不作为新增人口史实。

## 验证与代价

新回归检查覆盖117文件的实际字节及哈希、7类Worker响应、HEAD、304、错误指纹412、稳定路径重新校验、缺失存储503、真实读取器解压结果和并发共享。跨区预加载测试读取真实数据，并检查重试、复用与年份隔离。浏览器已查看742年详图的39条区划及永阳郡考证。

指纹模块增加12,628字节，gzip增加5,311字节，Brotli增加4,287字节；没有新增启动请求或提前解析历史数据。本轮改善的是重复访问与跨区准备，没有测出整站首访提速百分比，也没有声称概览边界的史料精度提高。

完整测试、HTTP检查、部署包和线上验证证据见本批目录。首次完整测试因新报告子目录未创建而停止，创建目录后重跑；随后发现旧图版测试把名称总数固定为80，改为核对原有50条记录完整保留，再重跑完整套件。两次失败日志均保留。旧版本报告还原，本轮重跑证据另存，最终发布见 `verification-3.59/publication.json`。

## 下一批重点

1. 用固定设备、冷/热缓存和限速条件测量首个可用地图、自动详图完成及交互延迟，按瓶颈安排后续优化。
2. 推进南亚单幅、明确年代图版的经纬网配准与独立残差核验，再做有出处的边界数字化；不从现代行政区拼装古代疆域。
3. 继续318条汉唐名称审校。此次另有11个暂缓项，其中8条原文人口数与源记录不同，待版本对读；这不等于已证实地名身份错误。庭州/北庭、阶州、合并单元和音读问题仍需专门处理。
4. 无详图地区需要更好的来源几何；曲线与缓存只能改善呈现和使用体验，不能替代史料补充。
