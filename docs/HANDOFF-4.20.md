# 经纬纪 4.20 · 同拼写区划与史籍户口对读

2026-11-23 · [在线图集](https://zhuozheng2006.github.io/meridian-atlas/)

## 从同一拼写找到对应区划

420 条研究区划中，有 207 条共享 77 种来源拼写。在目录展开「比较同拼写记录」，可以逐项查看年份、名称、来源上级、核查状态与编号，然后打开对应的区划地图或考证。Gui Zhou 一组有五条，其中两条都属岭南道。编号可用来分清同一道里的记录。浏览器后退会恢复展开的对照和刚才使用的链接。[桂州（742-64）](https://zhuozheng2006.github.io/meridian-atlas/?division=742-64#view=sources&lang=zh)

## 读数与出处

- 目录和地图档案共用一份考证。研究数据人口附取数方法，史籍的户数、口数列在各自版本的链接旁。227 条记录的 236 条引文有可逐项归属的读数，其中 220 条记录可由已存档的卷次、版本编号、文件校验值和原核查表复核。
- 修复了 82 处唐书标题锚点。103 条汉代引文可以直达《汉书》对应的户口段落。链接同时包含章节锚点，支持文本定位的浏览器可进一步定位到引文。[京兆尹（2-33）](https://zhuozheng2006.github.io/meridian-atlas/?division=2-33#view=sources&lang=zh)
- 例如永嘉郡的三种版本读数为 241,694、241,690 和 141,690 口。研究数据取 141,690，详情可分别打开原文核对。[永嘉郡（742-90）](https://zhuozheng2006.github.io/meridian-atlas/?division=742-90#view=sources&lang=zh)

## 本轮验证

使用 420 条真实索引记录，逐组检查了 77 组对照及其 207 条编号。目录和地图考证的中文、英文及双语显示逐条一致。另检查从第二批结果中的桂州进入其他同拼写记录后返回时的筛选、展开状态和键盘焦点。103 个汉代文本定位各自匹配存档中的唯一段落，344 个可以用本地存档验证的唐书标题锚点均命中。
