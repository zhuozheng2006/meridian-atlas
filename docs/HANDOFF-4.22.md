# 经纬纪 4.22.0 · 纸墨主题

[在线图集](https://zhuozheng2006.github.io/meridian-atlas/) · [样式维护说明](MAINTENANCE.md) · [上一版的地名与史料工作](HANDOFF-4.21.md)

地图、资料页和研究阅读器统一采用宣纸色底、墨色正文与古铜细线。页眉和时间轴保留乌木底和黄铜字，朱砂标出当前年份与阅读位置。这次发布集中在界面和导出，历史数据沿用 4.21.1。

## 这一版的变化

- 年份题签、图层按钮、详情卡、研究阅读栏和键盘帮助窗使用相同的纸面与字体。主题变量集中在 [theme.css](../public/theme.css)。
- 单图和双年份对照导出的 PNG 使用纸色边框与题注，保留年份和各幅地图的来源署名。
- 疆域面积图加深普通时段的柱条，朱砂标出当前时段。手机导航加深英文副标题。区域地图按钮的键盘焦点环绘制在按钮内部，事件卡向读屏软件标明当前选项。
