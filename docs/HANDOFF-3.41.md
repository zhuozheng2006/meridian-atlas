## HALC 选择性能与真实几何复用

`public/halc-boundaries.js` 使用 vector source 的 `promoteId` 与 `halcSelected` feature-state。打开、切换、关闭档案只改该选择状态，避免通过修改图层 filter 使整批瓦片重新解析。

- 普通选择层与普通边线共用固定 filter/layout；新增独立单元选择层与独立单元边线匹配，从而复用 MapLibre 的几何桶。透明颜色由选择状态控制。
- 同一原始 fid 的跨瓦片片段一起选择。切年、隐藏、现代参照、错误、来源重建和销毁会清理选择；普通移动与两幅地图保持各自状态。
- 直接使用捆绑 MapLibre 5.6.2 的 StyleLayerIndex、WorkerTile.parse 和实际瓦片 `6/32/20.pbf`：432个要素中，普通/独立两对图层确实共享 bucket、顶点和索引对象。
- 该瓦片线顶点从首个未共享候选的344,574减到172,287，线桶3→2，基础顶点及三角索引的 SHA 均不变。这个局部验证不能写成全世界地图体积减半。
- 真实 Style 测试中，200次旧 filter 选择触发200次来源重载；新状态选择0次。测试使用真实样式判断，DOM/GPU/传输是替代环境；不可当作浏览器统一提速倍率。
