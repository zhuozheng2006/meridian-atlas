# 世界历史图集 v3.9：HALC 1500 地区资料层与数据转换说明

本次提供一份可独立选择的 **1500 年低地国家地方单位地图**，补充全球疆域概览在这一地区的细节。它保留 HALC 原始地方单位及其历史属性，适合阅读地方行政、司法、宗教与自然区划的关系。

**覆盖范围为低地国家及邻接的法国北部、德国西部；本层不覆盖阿尔卑斯、瑞士或巴伐利亚，因此不能用于宣称已解决这些地区的 1500 年国界精度问题。** 覆盖矩形约为东经 0.5394°—8.3520°、北纬 48.5402°—54.0243°。矩形内有未覆盖区域，服务这些位置的空瓦片是正常数据。

English summary: HALC adds an independent locality-level reconstruction for the Low Countries and adjacent northern France and western Germany in 1500. It preserves local units and their original source attributes. It does not cover the Alps, Switzerland or Bavaria, and it is not a replacement for worldwide national boundaries.

## 几何如何转换

1. 从原始 GeoPackage 读取 WGS84 多边形，保留原文件。
2. 将坐标投影到 Web Mercator，按各缩放级别映射到统一的整数瓦片网格；MVT extent 为 8192。
3. 使用 Shapely `set_precision(..., mode='valid_output')` 进行网格量化。同一缩放层级的邻接瓦片采用同一全局网格。
4. 在整数网格上删除严格共线的冗余点，容差为零，并逐单位、逐层级断言转换前后拓扑相等。
5. 按带有 64 网格单位缓冲区的瓦片矩形裁剪，以相同整数网格计算交集，按 MVT 要求编码环方向。
6. 以 `halc_localities` 图层输出 MVT2；保留原始 `fid` 为 feature ID 和属性。完整非几何属性按 `floor(fid / 256)` 分片。

没有对地理边界进行人工平滑、手工补边、历史年代插值或 ADM1 合并。投影、量化和裁剪仍会改变显示坐标，极小几何部分可能在网格上坍缩，不能把瓦片称为与原始坐标逐点完全相同。原始几何始终可通过官方 GeoPackage 链接获取。

z6 有六条极小地方单位未形成可编码多边形，fid 为 `1970、7010、10002、11961、14141、14160`。其中三条在网格量化阶段整体坍缩，其余三条在后续瓦片编码中未保留可显示的多边形。z7—z10 及详情档案均保留全部 14,863 个 fid。超过 z10 的放大使用现有瓦片，不增加历史资料细节。

## 精度与历史含义

细密的矢量能减少粗网格的显示棱角，但其历史确定性仍由原资料和重建方法决定。在覆盖纬度范围内，z10 的一个整数网格单位约为地面 2.8—3.2 米；这是编码采样间距，**不是几何的历史定位误差或测绘精度**。

`QUALITY` 描述重建依据类别，保留以下原始分布，不将数值高低当作精度评分：

| QUALITY | 重建依据 | 记录数 |
| --- | --- | ---: |
| 0 | 主要依据近同期历史重建 | 647 |
| 1 | 主要依据其他时期历史重建 | 9,614 |
| 2 | 主要参照现代边界 | 2,890 |
| 3 | 主要参照地理或自然特征估计 | 392 |
| 4 | 主要参照历史边界估计 | 1,291 |
| 8 | 混合来源 | 2 |
| 9 | 位置未识别 | 27 |

`TYPE` 原始分类保留为：行政或司法单位 9,232 条，行政/司法与宗教区划合一 5,545 条，自然要素 86 条。自然要素可独立辨识，不赋予国家含义。

时间字段 `1500-01-01` 至 `1500-12-31` 标识本次来源重建快照，不能据此推导每一地方单位的精确存续日期。地图名称 `NAME` 使用来源的现代规范拼写。`NAME_EXT` 以及部分 ADM8、ADM9 含其他时期的对比统计名称，仅保留在原始资料详情，不能作为 1500 年同期名称展示。

完整保留共有或争议归属中的分号及原顺序。`XX` 是“小型独立领地”的分类，不能合成为一个国家。原始 ADM0 也有并列值，如 `HRR;FRA` 与 `FRA;HRR`，其顺序保持原样。

`SOURCE` 可按分号分解后查阅原始参考文献键，同时保留原文。源数据本身存在一条空 SOURCE：fid 10704，Servigny-lès-Raville；该缺项没有被推断填充。读者可结合 QUALITY、REMARKS 和原始代码本理解记录依据。

## 验证与可复现构建

首次完整审查已解码 84,950 个瓦片要素实例，逐一比对来源属性，核对几何有效性和瓦片缓冲范围；结果为零无效编码几何。每个详情记录均与原 GeoPackage 的全部非几何属性一致，z7—z10 包含全部 fid。每个覆盖矩形内的瓦片都存在，包括空瓦片。

日常发布检查复用这份完整审查，通过 SHA256 锁定同一批资产，不重复宣称进行了新的几何审查。正式 NOTICE 的文本替换单独记录前后哈希、字节数及原因；原 MVT、详情和代码本的核验结果保持不变。重建或修改数据后应重新运行完整审查并复核校验清单。

原始 GPKG 和 XLSX 通过上面的官方链接取得后，放入任意本地输入目录；不需要复制进 public。构建器核对官方 SHA1，不会删除已有输出目录，输出位置必须为新目录或空目录。报告应放在数据输出目录之外。不要使用 `python -O`，以保留完整构建和审查断言。

```sh
python3 -m venv .venv-halc
.venv-halc/bin/python -m pip install -r scripts/halc/requirements.txt
.venv-halc/bin/python scripts/halc/build_tiles.py --source SOURCE/HALC-1500.gpkg --codebook SOURCE/HALC-Codebook.xlsx --output work/halc-build/assets --report work/halc-build/build-report.json
.venv-halc/bin/python scripts/halc/verify_assets.py --source SOURCE/HALC-1500.gpkg --codebook SOURCE/HALC-Codebook.xlsx --publish work/halc-build/assets --build-report work/halc-build/build-report.json --report work/halc-build/verification-report.json
python3 scripts/verify-halc-data.py --data-dir public/data/halc --public-dir public --allow-extra labels.json
```

`SOURCE` 为原始输入目录，发布数据位于 `public/data/halc/`。便携构建器默认使用同目录正式 NOTICE，也可通过 `--notice` 显式传入已审核文本。构建所用版本为 Shapely 2.0.7、GEOS 3.11.4、NumPy 2.0.2、mapbox-vector-tile 2.2.0、protobuf 6.33.6、pyclipper 1.3.0.post6。GEOS、Python/zlib 与编码器环境可能影响输出字节；跨环境构建以完整审查确认语义与几何，再审核新的哈希，不自动放宽旧清单。

原研究脚本的工作区相对路径已在便携版改为明确参数；代码本审查直接从指定 XLSX 重新提取，不再依赖研究目录内的预提取 JSON。构建算法和原始属性处理保持一致。界面通过“图层 → 边界来源 → 低地国家 · 1500”选择，也支持两图独立对照。

本次便携性实测已完成：使用相同原始输入独立重建耗时约 68.7 秒，881 个资产中仅正式 NOTICE 改变，其余 880 个文件逐字节一致。便携版完整审查重新解码 84,950 个要素实例，零无效几何，全部来源属性相符，并直接从源 XLSX 重新核对五个字典文件。原始输入 SHA1 未变。具体证据保存在 `halc-reproducibility-report.json`、`halc-verification-report.json` 与 `halc-integrity-report.json`。
