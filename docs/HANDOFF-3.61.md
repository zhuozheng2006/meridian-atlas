# 经纬纪 3.61：首屏目录分包、唐代名称与南亚分期读图

## 本轮成果

主地图不再等待13765条跨年代记录全部下载。地图专用目录按25年分包，首屏只读取所选年份对应的包；跨分包换年与双图对照各自读取对应目录。每条记录的原始字段、几何引用、metadata与全局边界变更年份完整保留。全时期目录只用于完整检索、国家档案和资料页面，地图的局部目录不赋给全局研究目录。

生成217个日期包及1个范围外空包，合计2,999,270字节。原完整目录602,739字节；前250年包12,848字节，742年16,686字节，1492年25,996字节，1914年29,731字节。新增约3MB静态资源，不改R2对象。原始完整目录与原始记录下载保持不变。

## 加载与交互保护

- 首屏预加载准确指向所选年份的目录包；超出疆域年代范围时读取空目录，保留全局说明和边界变更索引。
- 共享同包请求，失败清除缓存供重试，拒绝错年代包。包内日期和原记录逐项核对，包含RELATION和原始ToYear=0端点。
- 新换年请求在等待目录之前使旧渲染请求失效；目录与地图年份在成功提交时一起切换。新请求失败后，仍保留上一次成功显示的年份、目录和疆域。
- 对照初始化捕获自己的年份和代次，旧包不能套用到新年份。关闭对照后，迟到请求无法恢复已移除的地图。
- 完整政体检索与档案显示加载、失败和重试状态。共享目录请求由其他入口启动时，当前检索仍会收到完成通知。关闭档案、换年或换政体后，旧请求不会重新打开档案。
- 前后边界变更跳转使用全局有序索引的副本，避免反转共享数组。政体深链接第一次加载失败后仍可重试恢复。
- 限速实验发现，目录更早就绪后，地形增强可能提前挤占历史几何带宽。因此本版先完成当年疆域，再启动可选地理增强。

## 名称核查

新增25条742年唐代名称：河南道15、关内道7、都畿道2、京畿道1。累计150/420条，汉62、唐88，剩余270条。所有别名按年份、PrefID、源名称、道名精确匹配。

两个源名Xu Zhou分别是许州→颍川郡（204）、徐州→彭城郡（224）。岐州742年对应扶风郡，未提前使用757年的凤翔府；源Cai Zhou对应742年汝南郡，蔡州名称始于762年。郓州源人口恰好等于原文郓州与济州合计，而合并发生754年、742年源目录仍另有济州，故暂缓。共15个新增待核项，没有把人口辅助核对当作新增人口史实。

证据附《旧唐书》卷38固定版本、原文压缩快照及哈希：`verification-3.61/tang-name-evidence.json`、`sources/old-tang-38.html.gz`。

## 南亚史料推进

孔雀王朝学术图版增加四段中英文分期读图：前305年之后的割让、至前273年的并入、约前260年的征服，以及阿育王在位期间的领土取得与殖民活动。来源副图的约前325—175年，与母版前321—181年分别说明，直接链接馆藏副图。

本轮实际下载并检查副图与原书制图规范，完成28个刻度约束、三种圆锥模型比较、9个留出约束及两处独立地点检查。华氏城和巴克特里亚的独立位置误差约58、69公里，未达到可发布边界的要求。完整失败证据和复现脚本保存于 `verification-3.61/south-asia/`，原始扫描仍由馆藏提供。本轮没有新增南亚年度矢量边界，也没有将图版的分期标注拼成同一年度疆域。

## 验证与实测

数据回归对照全部5424个有效历史年份、254592个记录—年份组合。启动回归和目录应用回归覆盖并行、失败、取消、重试、搜索全量语义、完整年代链、图层启动次序与目录原子提交。首次完整测试停在发布文件预算：旧检查误计了2928个R2对象。预算检查现与构建共享明确的对象清单，并断言清单与实际分流完全一致；实际静态文件17225个，继续保持20000文件及25MiB单文件上限。原始失败日志保留。完整测试、HTTP检查、部署包审计和线上字节核对见本批验证目录，发布结果见 `publication.json`。

基线当年疆域可交互时间9.455秒；最终两次为5.285、5.339秒。中间方案仅拆目录、仍提前启动地理层时为8.242秒，已保留这次实测，避免只呈现最佳结果。最终首屏没有请求完整目录。

浏览器对照使用同一本机预览、前250年南亚视角、1.5Mbps下载、0.75Mbps上传和150ms延迟，禁用主页面缓存；工作线程缓存未独立控制，不能称为完全冷启动。原始测量和中间方案结果见 `browser/startup-measurements.json`。这里“可交互”指当年疆域提交、年份控件开放，不表示所有可选地形与城市图层全部完成。
