## 证据与词义

名称核心来自UNESCO双语遗产页、外交部/驻外使馆的常用地名与历史称谓、中文学术论文。每个候选列出引用来源ID、完整URL、源行绑定与词义审核备注。Early、Late、I/II、Empire、Dynasty等修饰语严格取自Polaris原名；外部名称资料只证明中文词汇，不被冒充为每一阶段年代的独立证据。

- 四川大学馆藏宋德星、白俊《论印度的海洋战略传统与现代海洋安全思想》（2013年第1期）：取得完整原PDF 373,089B，SHA-256 `634c3c579153f66c3da481e9fd0e5993c3c0d1bbbebf5da9e966d46695197898`。PDF第5页/印刷第21页注①同时列出帕拉瓦、朱罗、潘迪亚；成功使用PDFium渲染并逐字查看。失败的Poppler中文缺字渲染不作为验证凭据。
- 蒋俊《从多元到聚合：尼日利亚约鲁巴民族的历史透视》（2015）：取得工具可读的PDF文字与页码，印刷第55页将奥约和Oyo对应。直接PDF下载403、页图缓存缺失，因此目录明确标为提取文本，未宣称下载原PDF或完成页图验证。
- 布干达采用外交部常用译名，UNESCO的“巴干达”另作检索别名；I/II保持来源阶段编号。
- 诺克两条原ID本来同名，保留两条及各自原始年代，包含来源的年0值；没有因常识重新划为早期或合并。
- 卡卡提亚外部名称页给1123—1323年，项目阶段1175—1324年保持原值；仅补名称。
- 阿坎保持研究族群/地区标签，没有添加王国、帝国等国家性质。
- Foys、Proto-Yoruboid、Early Niynginya、Ilú-ọba Ọ̀yọ́及其他本批未完全核实项没有自动规范化；未处理者逐ID见 `deferred.json`。
