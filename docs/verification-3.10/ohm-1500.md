## 1. 结论

1. 1500 年（以及对照年 1492）中欧窗口现在有一份**固化进仓库**的 OpenHistoricalMap 派生数据：`public/data/ohm-1500/`，1500 年 **98 条**、1492 年 **91 条**行政边界，全部是 OHM 原始几何（成员线段按原顺序闭合、坐标零改动、保留孔洞与多面）。
2. 地区详图新增一个与之配套的图层组（`ohm-frozen-wash / -edges / -partial / -selected`），在 1492/1500 且视野进入窗口时才加载并绘制；点击沿用原有档案弹窗（名称、起止年、面积、OHM 原始记录链接）。
3. 两个来源不会互相打架：瓦片图层会把已由固化数据绘制的 relation 过滤掉（按 osm_id 精确排除），因此同一条边界**不会双重描边**；固化数据用铁锈色描边 + 更强填充与瓦片档案区分。
4. 覆盖判定改为诚实口径：只有确实有 OHM 记录的地块才画；视野以阿尔卑斯为中心时徽标显示"局部详图 · N 条 · 空白处未收录"，档案目录里列出**经核对的未收录政体清单**（旧瑞士联邦、巴伐利亚公国、符腾堡、巴登、哈布斯堡奥地利、蒂罗尔），并给出该来源最近的记录年份作为证据。
5. OHM 里成员线段无法闭合成环的三条帝国圈（Oberrheinischer / Niederrheinisch-Westfälischer / Schwäbischer Reichskreis）**不补画**：它们只以"仅已闭合部分"的虚线圈呈现、无填充、不参与标签，弹窗中如实说明缺失段数。

## 3. 构建流水线（可复现）

`scripts/ohm/build-ohm-1500.mjs`

```bash
node scripts/ohm/build-ohm-1500.mjs --fetch   # 查询 OHM Overpass，并把原始响应缓存到 scripts/ohm/.cache/
node scripts/ohm/build-ohm-1500.mjs           # 用缓存重放，产出 year-*.json.gz + manifest.json + NOTICE.md
```

1. **取标签**：`rel["boundary"="administrative"]["admin_level"~"^(2|3|4)$"](44.0,4.5,50.5,14.5); out tags;` → 1856 条 relation。
2. **按年份筛选**：OHM 的十进日期约定为 `年 + (年内第几天 - 1 + 0.5) / 该年天数`，与瓦片属性一致（`1480 → 1480.00137`、`1661-02-28 → 1661.16027`，两者都是既有 `validate-regional.mjs` 里用到的真实瓦片值）。集齐 1492 或 1500 年 7 月 1 日快照有交集的 relation：**102 条**。
3. **取几何**：`rel(id:…); out geom;`（分批 60 条）→ 每条 relation 的成员 way 几何。
4. **串环**：只按"端点坐标逐位相等"把成员 way 首尾相接。不移动、不新增、不删除任何坐标；不做简化、取整、布尔修补。闭合的环按 outer/inner 分别收集；未闭合的链**丢弃并记录**。
5. **分洞**：inner 环用内部探针点做点在面内判定，归入包含它的 outer 环；无法归属的内环丢弃并记录（`unassigned_holes`）。
6. **面积**：球面环面积（Chamberlain–Duquette 公式，R=6371008.8 m），外环减内环，单位 m²。
7. **输出**：`year-1492.json.gz`、`year-1500.json.gz`（GeoJSON FeatureCollection，顶层 `metadata` 带来源、快照、窗口、空缺清单）+ `manifest.json`（逐 relation 的 id、名称、级别、起止、环数、未闭合段数、丢弃孔数、面积、顶点数）+ `NOTICE.md`。gzip 由 Node zlib 生成，可重复。

## 6. 运行时接入（`public/regional-boundaries.js`）

- 新增纯函数：`ohmCoversYear`、`ohmInView`、`ohmLayers`、`regionalFilterExcluding`、`ohmAreaLabel`、`ohmPartial`，常量 `OHM_ROOT/OHM_SOURCE/OHM_LAYERS/OHM_SELECTED/OHM_YEARS/OHM_BOUNDS`。
- `ensureOhm()`：仅在 `enabled && showBorders && !modern && zoom≥6 && year∈{1492,1500} && 视野与窗口相交` 时用 `readJSON` 取 `data/ohm-1500/year-<年>.json.gz`；加载失败静默退回瓦片档案（不装作有数据）。Node 单测环境无 `location`，因此不会发起网络请求（既有 15 + 24 项单测保持隔离）。

- `settle()/hit()/coverage()`：固化要素与瓦片要素合并去重（同 osm_id 以固化数据为准）、共同参与点击命中、共同参与"局部覆盖"采样。
- 徽标：`局部详图 · N 条 · 空白处未收录`（原先只说"局部详图"，不点明空白）。
- 档案目录新增"N 个当年政体在该来源中未收录"折叠区（名称 + 最近记录 + 快照核对说明）；地区详图说明文字注明"两来源都没有记录的地方留白"。
- 弹窗新增"记录面积（球面）"，并对残缺记录显示缺失说明；结束年份缺失时显示"来源未记结束"而不是含糊的"未记载"。

## 8. 未解决问题

1. **只做了 admin_level 2–4**。z≥8 时应用会把瓦片详图上限提到 6 级，6 级（县/乡）仍只有在线瓦片，没有固化数据。
2. **只覆盖 1492 / 1500 两个年份**。其他年份照旧走在线瓦片；OHM 静态抽取没有做插值或"最近年份"回退，避免用错年份的边界。
3. **三条帝国圈源数据不完整**（见 §5），目前以虚线圈 + 无填充 + 弹窗说明处理；更彻底的做法是等 OHM 补全成员关系后重建。
4. **面积口径**：本数据用球面地面面积；OHM 瓦片属性里的 `area` 对同一 relation（2815329 洛林）给出 25 407 100 000 m²，而球面地面面积是 11 079 720 564 m²，比值 2.293 ≈ 1/cos²(48.4°)，**看起来是 Web-Mercator 投影面积**（推断，未在 OHM 源码中确认）。因此弹窗只对固化记录标"球面面积"，瓦片记录不显示面积，避免两个口径混用。
5. **详图模式仍会隐藏全球概览**（`boundaries.applyVisibility`，属 `boundary-controller.js`）。1500 年详图现在有内容了，但若用户想看"OHM 细边界 + Cliopatria 粗疆域"叠加，需要 Lead 决定是否放开（本任务未改）。
6. **`ATTRIBUTIONS.md` 未更新**（不在本任务写入范围）。建议加入：OpenHistoricalMap 1492/1500 静态抽取，CC0，快照 2026-10-02。
7. 固化抽取的原始 Overpass 响应缓存在 `scripts/ohm/.cache/`（被 `.gitignore` 覆盖），仓库里保留的是派生数据与 sha256；重放到字节级一致需要重新联网取回同一快照（OHM 是活数据，快照会前进）。
