## 映射审核结果

173 项全部有简体标签。119 项已按原标识、既有代码本名称和栏目人工核对为同一概念，2 项为改名候选，51 项在当前 Equinox 观察词表中没有对应，1 项仍有缩写歧义。所有映射均设置 `allowRecordMerge: false`：同概念不等于不同版本的每条编码、日期或定义完全相同。

原工作簿有 82 个可接受的概念建议、72 个 `not found`、**19 个语义错误建议**。例如青铜被对应为铁、非文字记录被对应为文字记录、语系被对应为投石索、道德化超自然奖惩被对应为罢免统治者。`build-inventory.py` 使用逐项写明的人工对应，不使用最长子串、编辑距离或其他名称相似度作等价判断。

52 项没有直接采用旧观察标签，其中不少早已列在 2021 代码本中，只是当前 135 项 Equinox 数据导出没有记录。不能称它们全部是“新增历史变量”。其中 18 项标为 `provisional-definition-needed`，如宗教类别的 genus/family/alternate 范围、职业分工程度的判据、Crisis 后果各子字段。`sync_rel_pra_ind_beli` 的 sync 没有获得可靠展开，因此保留为“宗教实践与个人信仰（缩写待释义）”，不能自行定为同步或混融。尝试读取官方新版代码本页面返回 403；不以检索片段填补完整定义。

11 项有明确的建议单位，出处逐项保留。计量制度变量记录制度是否存在，不是度量值，不能加米或平方米。个人最快通行时间的单位是天；最远交通联络距离单位为千米。

## 数据与显示模型要点

- 173 个 Variables 键唯一，全部有实际观察；实际观察的 variable/sheet/section 均与词表一致。626 个政体的字符串 ID 与数值编号唯一；观察主体引用没有缺失或错配。
- 54,826 条观察双端日期为空，8 条仅一端为空。空日期保持为空，可另列政体背景范围，不能冒充该观察的精确起讫年。
- 4 条观察包含零年份，另有 1 条政体结束年份为零。保留来源数字 0，不擅自换算为公元前 1 年或公元 1 年。
- 8 条数值的 `value_from > value_to`。保留原始端点顺序并标为待核，不自动排序或计算均值。这两个字段也不能被解释成时间序列的起止值。
- 117 条观察有日期超出所属政体阶段。这不是统一的“坏数据”：危机后果可能持续到政体终结之后，不能统一裁剪。
- CrisisDB 的 21 个结果字段是字符串代码，不是布尔值；`DIS` 保留待核。120 行 other_polity 双空，46 行有完整且有效的目标；没有悬挂或半空引用。`is_disputed` 为 140 null/26 false，`is_uncertain` 为 143 null/23 false；null 不得转换为 false。
- 宗教表部分变量使用全拼 present/absent/unknown，其他表常用 A/P/U；A~P/P~A 的当前序列化细义尚未证实。推断、疑似和未知代码都不能折叠成“存在”。原文拼写 `enoblement`、continuity/continuation、salary/state 等不自动修正或归并。
