# Polaris 3.38 独立终审

本轮审查发现的两项边界缺陷已修复并独立复核：缓存清理不再漏掉暂停于 Promise 边界的旧请求；恢复过大页码不再让全局检索反复报错。此次没有修改生产代码；修复分别由负责 Store 和阅读器的代理完成。

## 最终验证

- **Store：27/27**。实际生产模块与发布数据，覆盖固定版本及文件校验、原始类型与来源身份、按表检索和完整导出、失败重试、取消与有界缓存。新增两组检查覆盖清理缓存的入口与 Promise 边界。
- **阅读器：25/25**。实际阅读器、Store 与发布数据，采用可控的轻量 DOM 测试环境。新增两项检查覆盖超大页码、领域/关键词下的末页、零结果及状态恢复；原有检查继续覆盖语言、分页、导出、输入法和迟到响应。
- **独立缓存复核：5/5**。四个查询入口在缓存目录后立即清理，以及底层读取返回后、公共入口恢复前清理，均拒绝旧请求并保持缓存为空；重新读取正常。
- **独立页码复核：6/6**。全档案 9999 页回到内部第 2401 页；危机资料回到第 6 页；单条和零条结果回到第 0 页；有效第 3 页保持；修正查询期间切换阶段不会被旧结果覆盖。危机下载仍包含完整 166 条。

页码数值为从 0 开始的内部状态，界面页码加 1。上述数量描述各自检查范围，不代表整个网站已经通过全部验证。

## 资料一致性

独立比对全部 626 个阶段分片与六张检索表，57,631 条原始类型记录逐条一致，来源身份无遗漏或重复；压缩与解压文件摘要匹配固定清单。四条零年、八条单侧日期、117 条超阶段日期、八条逆序数值端点均保留原样。危机资料仍有 21 个原字段，布尔 0、布尔 1 与空值保持区别。完整导出包含 57,631 个唯一来源身份。

10,000 组数值比较与独立的 BigInt 有理数比较一致；英文名称沿用原目录，所检查的英文词表与阶段说明没有混入中文。五组跨版本分期链接保留各自日期和记录数，没有合并观察记录。
