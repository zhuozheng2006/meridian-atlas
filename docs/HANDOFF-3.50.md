# 经纬纪 3.50：按缩放等级绘制边界

日期：2026-11-12。承接已发布并同步GitHub的3.49，继续用户授权的性能优化。

## 改动

全球疆域的显示曲线按缩放级别采用100米、20米、5米、2米的局部地面弦误差上限；这是显示曲线的采样参数，不是历史边界精度。zoom小于4、4至6、6至8分别用前三档，8以上恢复原有2米档。安全包络、共享节点、交汇保护和每环2%面积约束仍逐档计算。原始疆域、国家资料、点击查询与研究下载保持原值。地区详图及CShapes继续原显示路径。

缩放结束、跨过档位时重新提交对应曲线；同档位不触发额外提交。派生帧缓存区分档位，每个源集合只保留最近一档曲线结果，避免把所有精度常驻内存。曲线关闭时恢复原始轮廓，重新打开按当前缩放级别绘制。

## 验证范围

新增检查针对1492、1500、1945三份真实全球帧、全部四档：源字节不变、记录数和环数不变、环闭合与方向、面积约束、反转要素顺序的一致结果、放大恢复原精度、缩小恢复同档内容。所有既有安全包络夹具在三个新档位重跑。既有缓存测试继续对照冻结的原始绘制实现，明确在最高精度zoom8执行；低档精度另由新增检查覆盖。

Node试验中，1492年派生面与线数据由18,750,170字节降至4,205,784字节；1500年由19,124,216降至4,294,891；1945年由43,170,678降至9,528,037。这是内部绘图数据大小，不能解释为网络下载量。Node计算耗时仅作诊断，不作为线上浏览器速度。

浏览器对照采用同一最终候选代码、相同视口与相机，通过仅本地QA服务器切换固定2米对照／自适应采样。QA补丁只增加观测与对照开关，不进入发布服务器。原始测量、限速条件和检查结果见browser目录。

## 浏览器结果与输入修复

三对交替测试：固定2米采样的就绪绘制中位数5150.4ms，自适应4131.5ms，提前约19.8%；从提交开始到该绘制节点的中位数1312.5→544.1ms。具体条件为4Mbit/s、80ms、禁HTTP缓存、1512×900视口／1512×672地图、1492年、[25,18]、zoom1.54。最终对照期间没有并行运行验证进程。仍未达到首轮4秒目标，不将数字推广为线上所有用户速度。

实际zoom8观察恢复2米档；双图1500／1900可用。复现并修复旧的输入竞争：上一年加载完成会覆盖尚未提交的新年份输入。输入框现在保留草稿，提交、撤销或步进时明确结束草稿。浏览器确认1945加载完成后1500草稿仍在，Enter后地图切至1500；新增异步回归检查保留这一行为。性能对照完成后只改动输入保护与版本戳，边界采样实现未再变化。
