# G3：把固化 OHM 窗口扩到东亚（task-13）

承接竞品对标差距 **G3（全球逐年粒度）**。本轮把固化 OpenHistoricalMap 从「中欧 10 年」扩到**两个不重叠窗口、24 个（窗口×年份）快照、15 个不同年份**，并在运行时按视野自动选择窗口。

## 2. 运行时：多窗口

`public/regional-boundaries.js` 新增 `OHM_WINDOWS`（每个窗口含 id、双语名、页面相对 root、bounds、年份列表），并：

- `ohmWindowFor(bounds)`：取包含视野中心的窗口；中心不在任何窗口时取与视野重叠面积最大的窗口；都不重叠返回 null。`ohmWindowInView` 保留原有跨 180° 经线的处理。
- `ensureOhm()` 以 `窗口id|年份` 为键：换窗口或换年时**先把上一个窗口的几何清空**（`setData(空集合)`），再加载新文件，避免把中欧边界画到东亚视野上；同一个 source 用 `setData` 复用，不重建图层。
- 加载失败、年份不在该窗口列表、视野离开两个窗口时，一行数据都不画（图层隐藏，瓦片档案不受影响）。
- 诚实口径不变：sparse 年份自动模式不接管概览；徽标与档案目录写入窗口名（"OHM 固化详图（东亚 · 1700 年 · 30 条 · 陆地采样覆盖 96%）…"）。
- 瓦片去重仍是按 osm_id 精确排除（中欧 333 个 + 东亚 195 个 = 528 个 id），所以两个来源不会给同一条边界画两遍。

## 3. 验证

```
node scripts/validate-regional.mjs              → {"status":"passed","checks":15}
node scripts/validate-regional-continuity.mjs   → 24/24
node scripts/validate-halc-continuity.mjs       → 24/24
node scripts/ohm/verify-ohm-1500.mjs            → 83/83（覆盖两个窗口的全部年份）
```

verify 脚本的关键证据：

- **坐标逐位命中原始响应**：中欧 3 423 031 个 + 东亚 7 745 796 个 = **11 168 827 个**，全部命中各自窗口的 Overpass 缓存，0 个被移动/取整/新增。
- 每个年份文件 gzip 与解码 sha256 与 manifest 一致；metadata 的 window/year/snapshot 与运行时窗口声明一致（bbox 按 south,west,north,east 与运行时 west,south,east,north 互校）。
- 每个要素闭合、落在窗口内、面积为正、在自身年份可见；孔洞全部落在所属外环内。
- **跨年零泄漏**：同一窗口内，某年快照没有的 relation 不会通过该年的可见性过滤（不同窗口之间是独立作用域，不做跨窗口比较）。
- 瓦片过滤精确排除 528 个 id；空排除表时过滤条件逐字节不变。
- 源数据自身无法闭合成环的 relation 全部逐年在 `metadata.undrawable` 列出且**未绘制**（中欧 3 条、东亚 25 条，例如 黑龍江/雲南/福建/山東/盛京、평안남도、Chiêm Thành 877、Sukhothai Kingdom Mandala）。

## 4. 超过 8 MB 的年份与分片方案（本轮未实现）

东亚 1930（11.57 MB）与 1950（12.35 MB）超过 8 MB。原因是窗口内包含**苏联、英属印度、美国（含菲律宾）、中国**等巨型多边形（1930 年最大单条：РСФСР 405 459 顶点 / 232 个面，Soviet Union 189 231 顶点，中國 123 898 顶点），而规则要求几何不裁剪、不简化，relation 只要与窗口相交就整条保留。

可选分片方案（按推荐顺序）：

1. **按地理子框分片**：把窗口切成 2×2 子框（北西/北东/南西/南东），每年 4 个文件；运行时按视野加载相交的子框，同一个 relation 可能在多个子框中出现，按 osm_id 去重即可。改动只在构建脚本 + 运行时加载键（`窗口|年份|子框`），不动几何规则。
2. **按行政级别分片**：`L2-3` 与 `L4` 分成两个文件；缺点是本例的大文件主要由 L2（苏联/中国/印度）贡献，收益有限。
3. **按年份抽样**：对 1850 与 1910 之间的密集年份只保留 10 年一档；会让时间轴出现空档，不推荐。

## 5. 已知边界

1. 两个窗口**不重叠**，合计覆盖 15 个不同年份；其它年份、其它地区仍依赖在线瓦片，不做邻年或邻区顶替。
2. 东亚中世纪（1000–1300）源数据本身就稀疏（12–15 条、陆地采样 2–4%），因此列为 sparse：自动模式不会用详图替换概览，徽标会提示"该年固化详图偏少"。
3. 东亚窗口的 25 条 relation 因源数据成员线无法闭合成环而**未绘制**（多为清代省份与朝鲜道），已逐年在 manifest 与档案目录注明。
4. `public/data/ohm-eastasia/` 60 MB、`public/data/ohm-1500/` 26 MB；运行时按年加载，单次最重为东亚 1930/1950 的 ~12 MB gzip。
5. 中欧数据本轮从缓存重放，**几何逐字节不变**，但 year 文件因为新增 `window` 元数据而换了 gzip sha256；docs/verification-3.11/ohm-frozen-verification.md 的哈希表已加注说明。
