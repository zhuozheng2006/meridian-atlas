# 经纬纪 3.62.0：界面重设、加载分片优化、420项汉唐详考与南亚审计

## 本轮成果总览

本版本面向**加载性能、视觉美感与交互体验、汉唐地名史料真实度、南亚制图误差审计**四条主线完成全面升级，并保持零编造史实与零篡改原始几何原则：

1. **按需轻量化加载与分片检索（Milestone 1）**
   - 首屏地图、`Polities` 文明检索与单国档案完全脱离对 `603 KB` 全量 `data/fast/catalog.json.gz`（及全量 `446 KB` 事件文本）的启动依赖：
     - `data/fast/events-index.json.gz`（`40,632 B`，覆盖全部 `709` 条事件索引）承接地图与专题目录筛选，仅在打开详情、`Chronicle` 全表或按全文检索时才懒加载完整事件叙事。
     - `data/fast/polity-search-index.json.gz`（`77,986 B`）索引全部 `1,592` 组政体（含子时段中文/英文异名边界），搭配 `64` 桶分片档案链（均值 `7,969 B`，共 `13,380` 条记录），点击任意政体或检索结果只下载所在单一分片。
     - 清除静态 `<link rel="modulepreload">` 抢占，按当前视图精确预加载对应精简索引；`boundary-controller.js` 保留同步轻量 `country-archive.js` 导入，维持 `regional-boundaries.js` 的延迟加载边界。
   - 新增 `scripts/validate-polity-search-index.mjs` 与 `build-fast-search-assets.mjs --check`，断言检索排序、异名时段区间、年代边界与完整目录 100% 等价。

2. **制图色彩重设、悬停探查与零遮挡交互界面（Milestone 2 & 4）**
   - **历史矿物颜料制图配色**（`boundary-style.js`、`map-engine.js`）：重设 16 组低饱和古地图矿物色系、深海群青水体（`#0b2236`）、羊皮纸石质陆地（`#d8d0b8`）、大气晕影、浅米晕环（`#faf4e2`）叠加胡桃墨实线（`#352e23`）边界与高亮悬停层（`hover-fill` / `hover-outline` + `.map-hover-card` 实时国名与存续年代浮窗）。
   - **全局界面与多终端适配**（`index.html`、`app.js`、`product.css`、`cartography.css`）：
     - 顶栏与时间轴紧凑化；时间条拖拽新增实时 `#sliderPreview` 年份与时代徽标；年号输入支持对照双栏步进 `‹` / `›`；战役与酷刑/暴行过滤收敛至图层面板，保持地图右上方单一工具栏。
     - 地图导出升级为带年份、时代与来源水印的博物馆画幅 PNG。
     - 细致修整 `1280×720` 下 `#layerPanel` 高度避免遮挡缩放控件、Zoom ≥ 6 时 `.regional-controls` 与比例尺重叠、研究截面弹窗 `.historical-credit` 与 `下载这条记录` 按钮排版、顶部 `#langSelect` 下拉箭头还原、以及 `834×1194` 平板与 `390×844` 移动端双图对照防重叠。

3. **汉唐全部 420 项地方政区名称史料穷尽核查（Milestone 3）**
   - 在已保存并校验 SHA-256 与 Wikisource 永久修订号（`oldid`）的原典全文快照上完成剩余全部 `270` 条记录核对：
     - **汉代（公元 2 年，`103` 条）**：新增核准 `33` 条（`《汉书·卷二十八·地理志》`，`oldid=2605705`），累计核准 **95 / 103**；其余 **8** 项因读音/异体/户口尾数差异保留存疑（如丹扬 `405,171` vs `405,170`）。
     - **唐代（公元 742 年，`317` 条）**：新增核准 `81` 条（跨越《旧唐书·地理志》卷 38–41：`oldid=7904832 / 2691264 / 2690566 / 2690053`），累计核准 **169 / 317**；严格依据「天宝人口实数完全一致 + 道属一致 + 天宝元年改郡明文无歧义」原则筛选，显式排除并备考 **148** 项（含剑州 746 年改普安郡、果州/澧州道属差异、渠州生僻扩展字、坊州/冀州脱“郡”字、平/洺/瀛转写差韵尾/声母、同州冯翊读音与 `2-45` 一致性待核、饶州/绵州/郑州/慈州缺天宝改郡记、安南都督府两区共用 99,652、以及贝州/巂州录本讹字、两《唐书》人口尾差或 `HOH*5`/Gong 2019 推算条目）。
   - **全量覆盖**：总计已核准 **264 / 420** 项，逐条文档化存疑 **156 / 420** 项，**未核查条目数为 0**；证据完整保存于 `docs/verification-3.62/han-tang-name-evidence.json` 与 `docs/verification-3.62/sources/`。同时修复 `public/china-prefectures.js` 英文端硬编码 `juan 40` 问题，改为随记录出处动态显示卷 38–41。

4. **南亚制图敏感性与边界—遗址叠合审计（Milestone 4）**
   - `docs/verification-3.62/south-asia/audit_south_asia.py` 与 `model-sensitivity-and-congruence.json` 对施瓦茨贝格图版 `III.B.4`（`055_b`）28 个刻度约束补充 **4-DOF 各向同性相似变换** 与 **Everest 1830 椭球基准** 对照：证明 6-DOF 等距圆锥的 `3.73 km` 留出误差依赖 `+1.82%` 扫描横纵拉伸比；去除各向异性后等距（`10.80 km`）与兰伯特等角（`11.92 km`）残差接近，且华氏城（`52.53–58.87 km`）与巴克特里亚（`63.18–95.92 km`）系统偏差在所有 8 组模型中持续存在。
   - 借助库内 **9 处独立 Pleiades 考古聚落**核对孔雀王朝、巽伽、贵霜、百乘、笈多、伐迦陀迦与朱罗的 Cliopatria 年度多边形：记录了孔雀 `-250` 覆盖南部建志城（Kanchipuram）却偏离西北高附（Kapisa）`54.19 km`、巽伽 `-100` 偏离邬阇衍那（Ozene）`150.01 km`、伐迦陀迦 `450` 偏离塔伽罗（Tagara）`57.60 km` 等实证残差，不捏造也不强行拉伸几何；同时完成 OpenHistoricalMap（ODbL）与 `aourednik/historical-basemaps`（GPL-3.0）开源矢量边界适配性评审。
