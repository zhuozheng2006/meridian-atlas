# 经纬纪 3.58：南亚学术图版、名称核查与概览缓存

沿用原站点、所有者访问范围及 GitHub 仓库。最终版本、提交与线上验证见 `verification-3.58/publication.json`。

## 本批交付

- **南亚资料**：核对芝加哥大学 DSAL 收藏的 Schwartzberg《南亚历史地图集》三组图版：孔雀王朝 III.B.4/p18、笈多与伐迦陀迦 III.D.1/p25、早期大国比较 XIV.1/p145。资料页提供中英文导读，孔雀、笈多、伐迦陀迦档案按精确名称和年代关联原图。馆藏原图约6200×7800像素，按需打开，不影响地图启动请求。原图保留在馆藏阅读器。
- **年代区别**：笈多图版印刷年代约300—550年，目录标签为300—500；已记录差别。XIV.1的12幅分图比较不同时期最大疆域，不作为同一年政体集合。
- **汉唐名称**：本批新增50条汉代核查，累计80/420条（汉62、唐18），剩余340条。按年份、PrefID、PrefNAM、ProvNAM精确匹配，保留源名称及下载记录。人口数仅作为同一史料条目的身份核对线索。越嶲、会稽、牂柯/牂牁、丹扬/丹阳、甾川/淄川、勃海/渤海、千乘、琅邪等8项留待文字及读音复核。
- **概览绘制**：每个转角最多保留两个采样结果，复用未变的环与面积判断。5个年代、每年12次视野转换，与3.57冻结实现逐坐标一致，源坐标不变。本地热路径采样中位数由2.9—9.2ms降至0.7—2.5ms；冷路径结果有波动。这是绘制阶段测量，不是完整网页加载时间。
- **重复加载**：258个年代包及12个首屏年度包共270个gzip文件使用完整SHA-256请求指纹。仅正确指纹请求使用浏览器私有长期缓存，错误指纹返回412，无指纹路径保留原有重新校验。构建时验证实际文件哈希。R2数据及revision未变，所有导入接口继续关闭。
- **文案**：说明轮廓采样密度与默认曲线画法，纠正旧说明中地图从不平滑的过时表述；补充AWMC及最新OHM快照数量。

## 验证与发现

完整npm测试、13项HTTP检查、Worker检查、来源身份验证、60个视野转换坐标一致性和浏览器资料页/长沙国/孔雀档案检查通过。馆藏目录生成的阅读器链接参数顺序与阅读器实现不匹配；改用原图清单URL在前、canvasID在后的格式，已实际打开地图并验证缩放。对应链接格式有回归检查。

新指纹查询参数暴露了旧离线测试夹具只接受裸路径的问题，修正夹具后重跑全套通过。保留首次失败日志，旧版本验证文件还原；本次重跑结果另存 `rerun-reports/`。最终仅来源文案与资源版本戳调整后复验关联检查、重建部署包。

## 尚未解决与下一批

1. **本批没有新增南亚年度矢量边界**。三组学术图版是更可靠的研究起点；SDSU示例缺坐标系统/出处且地点有误，NATMO生产日期不能当作古代有效日期，均未作为精细边界引入。
2. 从单个明确年代图版开始，按经纬网配准，独立控制点报告残差；逐一辨认扩张阶段、属国、核心统治及最大范围，再进行可追溯数字化。不得借现代行政区替代古代边界。
3. 继续核查340条汉唐名称及合并单元；名称核查不等于几何精度审定。
4. 无详图地区沿用当前受约束共边曲线。本批减少重复开销，不增加原始边界证据或细节。仍须测量真实低速网络下的首帧、完整交互和详图切换，不能把局部微基准称为整体加载提速。
