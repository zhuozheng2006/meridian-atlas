## 城市档案：已实现的三项修复

1. `public/places.js` 的 attested 转换以前没有来源类型。`public/app.js` 的搜索署名为空，来源链接被标成城市人口数据，许可最终误落到 Reba、Reitsma、Seto。现在 attested-site 明确来源类型，署名、链接标题和来源声明逐条取自 `p.attested.sources`。当前 14 条遗址均验证过；城市人口、Pleiades、首都原有来源规则保留。
2. 城市篇章里程碑原先关闭详情后只切地图年；现在目标年必须能得到同一条来源的 `placeAtYear` 结果，才进入跳转。0 年、非整数、范围外、地点位置年代空隙以及不满足当前人口窗口时保留现状并提示，移除了旧记录兜底。两图独立，城市动作使用自己的导航令牌；加载失败保留旧档案，关闭、离开、换城市、地图销毁或替换后的迟到结果不能重开。
3. 人口记录跳年保留返回原政体的上下文。返回时先恢复原年份，再恢复已有的城市筛选、列表位置、镜头和焦点；按钮显示原年。持续阅读期间保留 Records 标签、滚动和年代按钮键盘焦点。为防完整档案慢载时短暂移除 Records 标签，同城更新保留已在阅读的面板，待新档案到达后一次更新；其旧标签、来源年仍明确属于原先记录。

另按根代理要求，将 `app.js` 的 Ctrl/Cmd+K 在研究页优先指向已展开书架的搜索框。没有修改版本、package、构建戳或研究目录文件。

## 257 个阶段中文回退的系统方案

实核 369 个已译、257 个回退，其中 245 个 untranslated、12 个 partial；详见 `phase-translation-audit.json`。地区集中于西非 52、东非 39、南印度 16，三组共 107，约 41.6%。下一批应以这些来源阶段家族为单位查证，如 Wagadu、Jenne-jeno 和东非王国/苏丹国，不逐条盲译英文。

1. 每条以工作簿 SHA + Polities 原行 + polity_id + 原名 + 原年代/地区建立审校卡，延续现有严格指纹。译名只改变展示/检索，不合并实体、不修改来源年代。
2. 先核对 Seshat 自身的阶段页面与原研究的阶段划分，再使用有明确对应实体的机构双语目录、遗产机构或学术参考资料确认中文专名；把“实体专名”与“研究分期标签”分开记录。I/II 等编号保留。只有名字相同或时间大致相邻不足以确定实体。
3. 记录权威页 URL、页码/段落、原词、中文依据、读取日期和内容指纹；批处理生成候选，逐家族复核后才纳入显示映射。未查证部分保留原文供搜索。
4. 12 个 partial 及明显来源异常单列复核：Cuzco 考古分期、Wu Confederacy、Median Persian Empire、Early Chinese、Romanov I/II 等不为中文覆盖率而删除原文限定；Malacca 重复占位、Napoleonic France 年代异常等也不能用常识静默“修正”。

现有 `validate-polaris-polity-names.mjs` 会核对指纹、原英文、原数据未改以及 369/257 数量；它不能代替外部译名证据。扩充时除了更新计数，还须补可审查的中文来源登记与异常专项检查。
