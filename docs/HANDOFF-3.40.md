## 详细边界的两层等待

### OHM 本地快照与在线补充独立就绪

`regional-boundaries.js` 改为按来源的内容完成、当前视口和后续 render 判断接管时机。全图 idle 保留为补偿触发，不再是唯一入口。

- 完整本地年度快照可先显示；在线来源迟到或失败不会隐藏它，档案和当前选择继续可读。
- 首次填色、边线、点击与在线同 ID 排除都等待相应完整渲染帧。透明查询图层先准备，不把半载入的在线边线混入本地完整帧。
- 保留既有自动覆盖比例、象限/中央检查和 sparse 限制；明确选择地区详图时仍可浏览局部资料。没有扩张来源覆盖范围。
- 同视口的短暂 live 或 frozen 重载均保留上一次完整目录和选择；真正错误、切年、换窗口会清理不再有效的记录。
- 内容世代与瓦片加载周期分开：`content(false) → 多次 tile loading → tile ready(true)` 不会丢失先前内容就绪证明。浏览器发现过这一候选缺陷，已加入真实顺序回归；失败材料仍保留。
- 视口、来源周期和陆地覆盖变化进入扫描键；无变化的 idle/render 不再重复做整套覆盖采样。
- frozen GeoJSON 指定 `tolerance:0,maxzoom:14`，原件坐标不变。

### HALC 自身就绪与首次样式接管

`halc-boundaries.js` 与 `halc-regions.js` 分别监听自己的来源完成，等待下一 render，再核对视口和加载周期。地方与地区线可独立完成。

浏览器还揭示第二层等待：旧接管操作把线层从隐藏改为显示、把透明度改成数据驱动表达式，引发 MapLibre 再次解析已下载的瓦片。因此本轮在资格范围内预建线层，首次接管只改常量或随缩放变化的透明度。

- 水域与普通地方单元的有效填色透明度仍为 .05 / .24；RGB、年代、几何和属性保持。
- 增加一个固定过滤的独立单元边线层，保持 `XX` 及复合归属在低缩放级别的强调；全部原缩放透明度节点保持。
- 选中轮廓依旧位于地方线之上。
- 直接加载捆绑 MapLibre 5.6.2 的真实 Style/StyleLayer 验证：旧操作触发 reload，新首次接管及地区线先后到达均不再触发来源重解析。测试替代的是 DOM/GPU/worker，不是复制其样式判断。

### 本机 PBF 无损压缩

`serve.py` 对 MVT/PBF 提供正确 MIME 与 gzip，GET/HEAD 一致，遵守 gzip;q=0，Range 请求走未压缩响应，Vary 与缓存失效有实际 HTTP 验证。最大测试瓦片 **2,274,292 → 1,157,115 B**，减少约 **49.12%**；解码 SHA 与原件相同。

这是本机服务的确认结果，尚未确认线上 ASSETS 的压缩行为。代码不改变地图几何或数据精度。
