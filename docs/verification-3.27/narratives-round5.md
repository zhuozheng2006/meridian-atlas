## 2. 引用规则（两条固定 + 一条通用）

**规则一（QID）**：引用任何 QID 只能来自项目 catalog 的 `verifiedWikidata` 或 en.wikipedia 的 `pageprops.wikibase_item`，绝不从记忆取。

**规则二（通用，本轮新增并列）**：**凡引用外部条目，一律从实体反查（Wikidata sitelink 或 pageprops.wikibase_item），不得按名称搜索取第一条。** 这条比"中文导言要核验"更根本——中英两侧都会错，而且错了看不出来。

- 证据：3.26 轮对英文条目做严格复核时查出 **5 条按名称抓错的条目**——`Q7352` 晋朝（英文条目是消歧义页 Jin）、`Q837855` 齐国（英文条目是**「气」的概念条目**）、`Q1501306` 伐迦陀迦、`Q756895` 谏义里、`Q824489` 新国家体制（条目写的是别的实体）。改由 Wikidata enwiki sitelink 反查后复核 **70/70 通过**。
- 本轮执行方式：**没有做任何新的外部查询**，只撰写已在 3.26 通过实体反查与核验的 34 个计划（英文条目已按 sitelink 重取，中文引用已按 pageprops 判定），规则是"由构造保证"的。

**规则三（中文侧）**：中文导言与英文条目不符时，**以英文条目为准**；中文引用只在 `pageprops.wikibase_item` 与政体 QID 一致时保留（3.26 核验：52 接受 / 18 拒绝）。
