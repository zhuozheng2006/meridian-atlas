# 经纬纪 3.52：全部固化地区快照采用无损传输

2026-11-12。覆盖中欧10份、东亚14份快照，共24份地区—年份组合、15个不同年份、1148条记录快照（不是1148个不同政体）。所有坐标、属性、年代、孔洞及元数据逐项严格还原一致；没有原始几何回退记录。原始89,627,277字节，传输51,895,986字节，减少42.1%。这是下载数据量，不等于浏览器耗时下降42.1%。

传输文件统一存入现有私人站点的R2，以逐文件SHA256定位、校验和回读；原始资料继续保留，压缩文件失败时回退原文件。自动选择严格匹配窗口与年份，不借用最近年份。沿用3.51的提前预取、4秒优先窗口、在线补充兜底和原始精度渲染。未扩大来源宣称的历史覆盖。

完整测试、HTTP检查、构建和存储路由验证通过。新测试涵盖东亚与中欧的URL选择、未收录年份、损坏传输包回退；24份文件均生成确定性的字节校验并完整还原。第一次完整测试的旧夹具没有填写窗口年份清单，修正后完整重跑通过，保留失败日志。浏览器确认1300年东亚和1900年中欧均使用新传输文件，年代和来源匹配，自动显示详图；截图在verification-3.52/browser。

发布分为同一受众内的限时数据导入、逐项回读、关闭导入入口三个步骤；确切发布信息与云端数据回读证据保存在verification-3.52目录。下一批继续补充不列颠群岛有年代的详图，并改善详图缺位时的全球概览。此前参考资料：[OHM](https://www.openhistoricalmap.org/)、[CHGIS](https://chgis.fas.harvard.edu/data/chgis/v6/)、[Historical Basemaps](https://github.com/aourednik/historical-basemaps)。后两者此次仅核查来源，未混入当前疆域。
